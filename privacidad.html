Política de Privacidad — Automatizacion

Última actualización: 22 de septiembre de 2026

1. Quién trata los datos

Esta aplicación es una herramienta personal desarrollada y operada por Jaime Navas para uso propio.

2. Qué datos se tratan

La aplicación accede únicamente a los datos necesarios para publicar vídeos en las cuentas de YouTube y TikTok del propio desarrollador, mediante las APIs oficiales de cada plataforma (autenticación OAuth). Esto incluye: tokens de acceso, metadatos del vídeo (título, descripción) y el archivo de vídeo a publicar.

3. Cómo se usan los datos

Los datos se usan exclusivamente para automatizar la subida y publicación de contenido propio. No se recopilan datos de otros usuarios ni se comparten con terceros.

4. Almacenamiento

Los tokens de acceso se almacenan de forma local y cifrada en el entorno de automatización (n8n), gestionado por el propio desarrollador. No se envían a servidores externos ajenos a las plataformas oficiales (Google/YouTube y TikTok).

5. Derechos del usuario

Al tratarse de una herramienta de uso estrictamente personal, el único usuario de la aplicación es el propio desarrollador, quien puede revocar el acceso en cualquier momento desde la configuración de su cuenta de Google o TikTok.

6. Contacto
